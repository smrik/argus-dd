# 0004: Portfolio and learning project first, sales optional

Date: 2026-10-10 · Status: accepted (revisit by 2027-04)

## Context
The author works in FDD on a student contract, plans to leave by about 2027-04 (likely for a PhD), and does not see FDD as a long-term career. A full startup is a poor fit for now, but the idea may have commercial value.

## Decision
- Optimise for a working, well-documented, demonstrable tool: one end-to-end slice (synthetic TB → wrangling → mapping → AJPES cross-check → databook → slides) rather than breadth.
- Use only synthetic or public (AJPES) data, so the demo can be shown publicly.
- Keep the commercial option open: have 2–3 practitioner conversations, and add no licence that gives the code away until the sales question is settled.
- No SaaS, multi-tenant or company setup work.

## Consequences
- Code quality, tests, README and a reproducible demo count as deliverables.
- Repo visibility and licence are an open decision: public helps the portfolio; private or source-available preserves sales options.
- Revisit this decision when the author leaves FDD.
