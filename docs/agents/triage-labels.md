# Triage labels

Map the engineering skills' canonical roles to these casual GitHub labels.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-a-look` | Take a look and decide what to do. |
| `needs-info` | `need-more-info` | Need more details before moving on. |
| `ready-for-agent` | `ready-for-ai` | Clear enough for an AI agent to work on. |
| `ready-for-human` | `ready-for-me` | Ready for a person to work on. |
| `wontfix` | `not-doing` | Decided to leave this one alone. |

When a skill names a canonical role, use its mapped GitHub label.
Edit the GitHub-label column later to change the wording.
